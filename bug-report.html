#01 metrics.py 指标阈值与 ORCHESTRATOR.md/SKILL.md 完全不一致 Critical
问题位置
tools/metrics.py 第 18-23 行（文档注释）及第 286-295 行（THRESHOLDS 字典）
问题描述

Python 工具中定义的指标门限与 ORCHESTRATOR.md/SKILL.md 中规定的门限差了 4-5 倍，导致工具会放行本应不达标的章节，同时纠正建议中的阈值也是错误的。

指标metrics.py 代码值ORCHESTRATOR.md / SKILL.md 文档值偏差倍数
σ²（句长方差）≥ 25≥ 1204.8x
TTR（用词多样性）≥ 0.25≥ 0.481.9x
EGR（情感颗粒度比）≤ 0.60≤ 2.03.3x
Pσ²（段落长度方差）≥ 80≥ 3003.75x
# metrics.py 实际代码 (第 286-295 行)
THRESHOLDS = {
    "sigma2":  {"min": 25,   ...},   # 文档要求 ≥120
    "ttr":     {"min": 0.25, ...},   # 文档要求 ≥0.48
    "egr":     {"max": 0.60, ...},   # 文档要求 ≤2.0
    "psigma2": {"min": 80,   ...},   # 文档要求 ≥300
}
修复建议

将 metrics.py 中 THRESHOLDS 字典和 CORRECTIONS 字典的阈值统一改为 ORCHESTRATOR.md 中定义的值：σ²≥120, TTR≥0.48, EGR≤2.0, Pσ²≥300。同步更新文件头部的文档注释。

#02 chapter-word-counter.py 字数标准 (2600-3300) 与文档要求 (1200-1500) 矛盾 Critical
问题位置
tools/chapter-word-counter.py 第 41-42 行：DEFAULT_MIN_WORDS = 2600, DEFAULT_MAX_WORDS = 3300
问题描述

ORCHESTRATOR.md 和 SKILL.md 全文反复强调单章字数标准为 1200-1500 字（见 ORCHESTRATOR.md 第 477、512、703 行，SKILL.md 第 196 行），但字数统计工具的默认阈值设为 2600-3300，是文档要求的两倍以上。

后果：每一篇符合 1200-1500 字标准的正确章节都会被工具判定为"字数不足"，导致 G4/G7 门禁永远无法通过。

# chapter-word-counter.py 第 41-42 行
DEFAULT_MIN_WORDS = 2600   # 应为 1200
DEFAULT_MAX_WORDS = 3300   # 应为 1500
修复建议

将 DEFAULT_MIN_WORDS 改为 1200，DEFAULT_MAX_WORDS 改为 1500。同步更新 epilog 帮助文本中的字数说明。

#13 feishu_sync.py --force 模式使用 trigger="force" 不在合法值集合中 Medium
问题位置
tools/feishu_sync.py 第 422 行（sync_all_chapters 函数）vs 第 51 行（VALID_TRIGGERS）
问题描述

sync_all_chapters() 函数在第 422 行调用 sync_single_chapter(chapter_num, trigger="force", state=state)，但 "force" 不在 VALID_TRIGGERS = {"g4", "g7", "gate4", "gate7", "manual"} 中。

这会导致每次强制全量同步时，每个章节都会触发警告："未知触发类型 'force'，使用默认 'manual'"，虽然不阻塞但会产生大量噪音日志。

# 第 51 行
VALID_TRIGGERS = {"g4", "g7", "gate4", "gate7", "manual"}

# 第 422 行
success = sync_single_chapter(chapter_num, trigger="force", state=state)  # "force" 不在集合中
修复建议

将 "force" 加入 VALID_TRIGGERS 集合，或将第 422 行的 trigger="force" 改为 trigger="manual"。

#15 metrics.py VAGUE_EMOTION_WORDS 存在重复词条 Low
问题位置
tools/metrics.py 第 45-59 行
问题描述

VAGUE_EMOTION_WORDS 集合中存在重复词条：

  • "愤怒" 在第 46 行和第 50 行各出现一次
