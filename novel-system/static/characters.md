# 《誓约改签：我把原勇者的后宫线全抢了》人物档案设定集

> 题材：百合 / 凤傲天 / 游戏穿越 / 系统 / 异世界 / 喜剧
> 世界：圣约大陆（小世界）
> 核心体系：五圣约誓约机制
> 原游戏：《闪耀吧！勇者的五圣约》

## 一、主角档案

### 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 莉娅·科尔文（Lia Corvinus） |
| 年龄 | 17岁 |
| 身高 | 162cm |
| 身份 | 圣约学院二年级生 / 穿越者 / 誓约改签者 |
| 属性 | 无（表面）/ 誓约篡改（隐藏） |
| 别称 | 誓约小偷、剧本破坏者、艾莉诺拉的噩梦、那个女人 |

### 外表标签——反差感拉满

**表面印象：人畜无害的治愈系软妹**
- 栗色微卷中长发，发尾带一点自然的浅棕挑染，常年扎低马尾
- 琥珀色眼睛，笑起来会弯成月牙，左眼下有一颗小小的泪痣
- 身形纤细偏单薄，看起来像风一吹就倒，皮肤偏白
- 常年穿着洗得发白的学院制服，领口永远扣到最上面一颗
- 随身带一本封皮破旧的笔记本（实际上是前世游戏攻略手抄本）

**实际反差：**
- 力气大得离谱（穿越后锻炼身体的副产物，用来执行骚操作）
- 跑步速度堪比剑士（被艾莉诺拉追出来的）
- 手指灵活得可怕（改签誓约纹章时需要极致精准）
- 关键时刻气场会突变，泪痣像在发光，整个人从"软妹"切换成"幕后黑手"模式

### 核心能力 + 金手指

#### 1. 多世界线预知（被动型）
- **原理**：前世全路线全结局通关玩家记忆，知道原游戏每条线的关键事件、flag、隐藏剧情
- **范围**：前期覆盖前中期剧情，后期因蝴蝶效应逐渐失效
- **精度**：大方向准确，细节会偏差——偏差程度与主角介入程度正相关
- **代价**：
  - **记忆侵蚀**：每使用一次预知干涉剧情，前世记忆就会模糊一分（忘记现实世界的家人、朋友、自己原来的名字）
  - **世界排斥**：预知偏差越大，"世界修正力"越强，会以各种意外形式反噬（踩香蕉皮、被花盆砸、迷路绕远路）
  - **剧本依赖症**：知道得越多，越不敢偏离剧本，形成心理枷锁

#### 2. 誓约改签（金手指·主动型）
- **原理**：利用五圣约机制的规则漏洞——"誓约的成立取决于双方的真心认可，而非勇者身份本身"。只要能让圣约之人在心中承认"这个人值得我立誓"，誓约纹章就会向认可度更高的一方偏移
- **操作方式**：在艾莉诺拉与圣约女主即将立誓的关键节点，提前介入制造"更深刻的羁绊瞬间"，让纹章改签
- **视觉表现**：改签瞬间，誓约纹章会从金色（勇者）变为深紫色（异常），再转为银紫色（莉娅的誓约）
- **代价**：
  - **神灾反噬**：每改签一条誓约线，莉娅承担的神灾抗性压力就增加一份——不是因为她是勇者，而是因为她"偷"了勇者的庇佑
  - **誓约侵蚀**：改签的誓约不稳定，需要定期与圣约之人"补魔"（不是那个意思！是共同战斗/深度交流强化羁绊），否则纹章会褪色并回流给艾莉诺拉
  - **身份暴露风险**：改签次数越多，圣教会的"誓约监察法阵"越容易定位到异常波动
  - **艾莉诺拉的怒火**：每次改签，艾莉诺拉都会感受到神威被窃的刺痛，对"誓约小偷"的恨意+1

### 致命缺陷 + 前史创伤

#### 致命缺陷：预知依赖症
- 凡事都要翻"剧本"，一旦剧情偏离已知轨道就会陷入焦虑
- 剧本全崩时（中期某个大事件彻底偏离）会进入自我怀疑状态，甚至躲起来逃避
- 口头禅式自我质问："不对啊……剧本里不是这样的……"
- 深层恐惧：如果一切都不在掌控中，那自己还有什么价值？

#### 前史创伤：前世的"透明人"
- 前世是个普通到不能再普通的社畜，996加班族
- 家庭关系淡漠，朋友寥寥，存在感极低——团建永远被忘记名字，聚会永远是拍照时被裁掉的那个
- 唯一的精神寄托就是《闪耀吧！勇者的五圣约》这款游戏，刷了全路线全结局，是论坛上的"全图鉴大佬"
- 穿越契机：连续加班72小时通关DLC最终隐藏结局，猝死在电脑前
- **深层渴望**：被人记住、被人需要、有一段"非你不可"的关系——这也是她执着于抢誓约的潜意识动因（她自己前期没意识到）

### 人物弧光：从"我知道剧情"到"我创造命运"

**阶段一：剧本玩家（前期）**
- 心态："我知道所有flag，我要走最优解"
- 行为：精准卡点、规避风险、按剧本抢誓约
- 状态：自信满满，骚操作频出，喜剧担当

**阶段二：剧本偏离（中期转折）**
- 触发点：某个关键事件因蝴蝶效应彻底崩盘，预知完全失效
- 心态崩塌："为什么会这样？我明明都算好了……"
- 行为：自我封闭，试图用更极端的方式把剧情扳回去，结果越弄越糟
- 最低点：被艾莉诺拉找到，狼狈不堪，第一次在别人面前露出脆弱

**阶段三：破而后立（中后期）**
- 转折点：艾莉诺拉的某个举动（不是帮助，而是点醒——"你算计来算计去的样子，真难看"）让她开始反思
- 成长：放下预知依赖，开始用"心"而非"剧本"去理解身边的人
- 变化：骚操作还在，但动机从"完成攻略"变成了"保护她们"
- 标志事件：主动放弃一次预知机会，选择跟随直觉，结果反而更好

**阶段四：命运创造者（后期）**
- 心态："剧本？那是什么？我自己的路我自己写"
- 能力升华：预知能力进化——不再是"读取剧本"，而是"感知可能性"，不再受限于原游戏
- 终极蜕变：面对叙事层危机时，以"篡改者"的身份主动改写规则，而非被动利用漏洞
- 弧光闭环：从"想要被需要"到"被所有人需要，并且值得被需要"

### 喜剧属性：抢誓约时的骚操作

1. **圣女线**：提前三天蹲在圣女必经的"救赎小巷"，把原游戏里艾莉诺拉救的小猫先救了，结果猫挠了她一脸——圣女出来看到的是"一个满脸猫爪印还在笑的笨蛋"，印象分反而满了
2. **大小姐线**：在剑术大赛上故意用"预知"躲开所有攻击但不反击，把维奥莱特气得剑都歪了——赛后维奥莱特堵她，她递了瓶水说"你打的很好看"，傲娇大小姐当场CPU过载
3. **歌姬线**：在歌姬演唱会的"知音环节"，用前世游戏里的歌词接了下一句——莉丽丝当场愣住，因为那首歌她只写了一半，还没公开过
4. **公主线**：在政治晚宴上用"预知"避开了三次针对公主的暗算，公主以为她是顶级刺客，调查了她三个月——结果发现她真的只是个普通学生
5. **学生会长线**：利用预知把学生会要查的违规事件全提前摆平了，米蕾娅盯着"零违纪记录"陷入了存在主义危机——这个人是完美市民还是违规之王？

### 口头禅

| 时期 | 口头禅 | 场景 |
|------|--------|------|
| 前期 | "剧本里是这么写的" / "让我算算时间" | 做决策前翻笔记本 |
| 前期 | "啊这……不在剧本里啊" | 遇到意外 |
| 中期 | "不对……不应该是这样的……" | 剧情偏离时的焦虑 |
| 后期 | "管它什么剧本" / "我选第三条路" | 打破规则时 |
| 后期 | "——因为你值得" | 对圣约女主们说真心话时 |
| 通用（喜剧） | "艾莉诺拉你听我解释！" | 被抓包时的标准开场白 |

### Soul Field 铁律

**铁律一：绝不主动伤害无辜者**
- 即使算计再深，底线是不牵连无辜
- 违反条件：触及"保护的人"这条红线时，会短暂突破——但事后一定会自我惩罚
- 铺垫要求：至少5章展示她如何费尽心思把无关人员移出风暴圈

**铁律二：绝不向艾莉诺拉认输（前期）**
- 每次被艾莉诺拉堵到，嘴硬到底，绝不承认自己是"誓约小偷"
- 转变：中期动摇后，这条铁律逐渐松动
- 彻底打破：后期某个生死关头，莉娅主动向艾莉诺拉坦白一切并请求帮助

**铁律三：笔记本不离身**
- 那本破旧的笔记本是她与前世最后的联系
- 后期记忆侵蚀到几乎忘记自己是谁时，笔记本是她的锚
- 符号意义：从"攻略本"到"日记本"，记录的内容从剧情变成了身边人的喜好

### 语言指纹

- 语速中等偏快，想到什么说什么，但涉及算计的时候会变慢
- 喜欢用比喻，而且比喻经常很接地气（前世社畜后遗症）
  - "这波稳了" "血赚不亏" "地狱难度开局"
- 紧张的时候会不自觉地抠笔记本封皮
- 自嘲倾向严重，遇到挫折先自己吐槽自己
- 关键时刻会突然变得很认真，语气降八度，反差感极强
- 标志性句尾："——相信我。"（认真模式）

## 二、艾莉诺拉档案

### 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 艾莉诺拉·圣光之誓（Eleanora Vow of Light） |
| 年龄 | 18岁 |
| 身高 | 175cm |
| 身份 | 第77代勇者 / 圣约学院三年级生 / 原游戏主角 |
| 属性 | 光 / 勇者神威 |
| 别称 | 勇者大人、诺拉（亲近者用）、那个后宫王（莉娅私下吐槽） |

### 外表

- 及腰金色长发，发梢自然微卷，阳光下会折射出神圣的光泽
- 翡翠绿眼眸，眼尾微挑，自带威严感——被她盯着看会有"被审判"的错觉
- 身材高挑挺拔，常年穿白金色勇者制服，披风从不离身
- 左手手背上有金色的勇者纹章，发动神威时会发光
- 走路带风，气场两米八，所到之处自动让道
- 有一个细节：披风内侧有很多补丁——是每次战斗后自己缝的，不让别人知道

### 核心能力

#### 1. 勇者神威
- 圣约大陆最高级别的力量体系，天生的勇者之证
- 能力：全属性加持、神灾抗性、誓约共享
- 视觉表现：金色光芒环绕，身后隐约有圣剑虚影

#### 2. 断誓承压反升
- 五圣约机制的副作用正向利用
- 原理：一人断誓，勇者承压反升——压力越大，力量越强
- 艾莉诺拉的玩法：故意让誓约处于"半断"状态来维持高压修炼
- 但莉娅的改签不一样——不是断誓，是"转移"，压力直接没了，力量反而流失
- 这也是艾莉诺拉恨"誓约小偷"的根本原因：不仅抢了人，还抢了力量buff

### 致命缺陷

**骄傲到骨子里的孤独**
- 从小被当作勇者培养，所有人都对她毕恭毕敬，没有人把她当"普通人"
- 表面上享受众星捧月，内心深处极度孤独——"她们喜欢的是勇者，不是我"
- 绝不承认失败，哪怕心里已经认可对方，嘴上也绝不会说
- 深层渴望：有一个人能看穿"勇者"的外壳，看到真正的她

### Soul Field 铁律

**铁律一：绝不低头求人**
- 人生信条："勇者不求人"
- 哪怕身陷绝境，也只会自己扛
- **唯一破例**：为了莉娅——后期某个关键时刻，艾莉诺拉第一次低下头请求别人帮助莉娅
- 铺垫要求：至少5章展示她如何死撑，哪怕盟友全灭也不求助的过往

**铁律二：绝不背后偷袭**
- 骑士道精神深入骨髓
- 战斗永远正面刚，绝不耍阴招
- 这也是她前期拿莉娅没办法的原因——莉娅全是阴招，她不会

**铁律三：保护弱者是勇者的天职**
- 哪怕是"敌人"，如果是弱者也会出手相救
- 中期救过一次陷入危机的莉娅，救完之后自己气了三天——"我为什么要救那个誓约小偷！"

### 语言指纹

- 语速慢而清晰，每一个字都像经过掂量
- 命令式语气，习惯了别人听从
- 喜欢用"理应""应当""必须"等确定性词汇
- 很少用疑问句——不是不问，而是习惯了自己找答案
- 情绪激动时语速会变快，但措辞反而更正式（用正式感掩饰情绪）
- 标志性开头："听着——"（准备说教/下令时）
- 动摇时的特征：会不自然地握拳，或者用披风裹紧自己
- 被莉娅气到的时候会咬牙切齿地叫全名："莉——娅——！"

### 反收转变六阶段

#### 第一阶段：敌对（第1-15章左右）
- 状态："誓约小偷？竟敢挑衅勇者的权威，找死。"
- 行为：到处堵莉娅，要把她抓起来审问誓约改签的秘密
- 每次堵到都被莉娅用各种骚操作逃脱，怒火值节节攀升
- 心态：这个人是害虫，必须铲除
- 标志性事件：第一次交手，艾莉诺拉拔剑，莉娅递了一块手帕说"你披风破了"——艾莉诺拉当场愣住，莉娅趁机跑了

#### 第二阶段：迷惑（第16-35章左右）
- 状态："这个人……到底想干什么？"
- 触发点：发现莉娅改签誓约后，并没有滥用圣约女主们的力量，反而在帮她们
  - 帮圣女摆脱教会控制
  - 帮维奥莱特解开剑术瓶颈
  - 帮莉丽丝找到失落的乐谱
  - 帮公主化解政治危机
  - 帮米蕾娅——嗯，帮她扣分扣得更有水平了
- 迷惑：她不是誓约小偷吗？小偷会做这些事？
- 心态动摇：开始怀疑自己的判断
- 标志性事件：某次神灾来袭，莉娅挡在圣约女主们前面，明明力量不如艾莉诺拉，却硬撑着不肯退——艾莉诺拉第一次觉得"这个人的背影……好像也挺可靠的"

#### 第三阶段：动摇（第36-60章左右）
- 状态："我为什么……会在意她？"
- 触发点：中期剧情大崩盘，莉娅预知失效陷入自我封闭
- 艾莉诺拉找到她的时候，看到的不是那个满嘴骚话的誓约小偷，而是一个抱着破笔记本发抖的普通人
- 心态变化：从"恨"变成了"……有点在意"
- 行为变化：不再追杀，开始不自觉地关注莉娅的动向
- 嘴硬表现："我只是在监视誓约小偷，免得她搞破坏！"
- 标志性事件：莉娅生病，艾莉诺拉犹豫了三秒，还是把药放在了门口——被维奥莱特撞见，被调侃了一个月

#### 第四阶段：心动（第61-90章左右）
- 状态："不……不可能……我怎么可能对那个人……"
- 触发点：莉娅彻底走出预知依赖，开始用自己的方式保护所有人
- 某次战斗中，莉娅挡在艾莉诺拉面前，笑着说"这次换我保护你"
- 艾莉诺拉的心跳漏了一拍——然后她把这归结为"神灾抗性波动"
- 行为：开始主动找理由接近莉娅，但每次都嘴硬
  - "我只是来确认你有没有搞小动作"
  - "顺路而已，谁特意来找你了"
  - "哼，这点小事，本勇者顺手就做了"
- 标志性事件：莉娅开玩笑说"勇者大人不会是喜欢上我了吧"，艾莉诺拉当场脸红到耳根，拔剑就砍——当然，砍偏了

#### 第五阶段：挣扎（第91-120章左右）
- 状态："我是勇者……我应该收五位圣约之人……可是……"
- 内心战争：
  - 理性：我是勇者，五圣约是我的使命，莉娅是誓约小偷，是敌人
  - 感性：可是和她在一起的时候……很轻松
- 挣扎表现：忽冷忽热，时而冷淡时而在意，把莉娅都搞懵了
- 转折点：某次生死危机，莉娅为了保护艾莉诺拉受了重伤
- 艾莉诺拉抱着浑身是血的莉娅，第一次说出了真心话："……别死。"
- 标志性事件：在莉娅昏迷期间，艾莉诺拉守了三天三夜——被五位圣约女主集体撞见，六人对视，气氛微妙

#### 第六阶段：确认（第121章+）
- 状态："……好吧，我承认了。"
- 触发点：莉娅醒来后，艾莉诺拉沉默了很久，然后说了一句——

- 人生导师——在莉娅迷茫的时候，用"酒鬼式哲学"点醒她

#### 前史——为什么他会帮莉娅？
- 年轻时是个很厉害的冒险者，有一个搭档（女的，你懂的）
- 搭档在一次神灾任务中牺牲了——而他因为"遵守规则"没能救她
- 从此隐退，躲在小公会里当分会长，天天喝酒
- 他看到莉娅的时候，想起了年轻时的搭档——一样的不按套路出牌，一样的嘴硬心软
- 他帮莉娅，其实是在弥补当年的遗憾

#### 与主线关系
- 前期：情报来源，偶尔吐槽莉娅的骚操作
- 中期：在莉娅被圣教会和王国双重通缉的时候，给她提供庇护
- 后期：在最终决战中，召集了当年的老伙计们，组成了"老头老大妈战队"（他自己起的名字），成为重要战力
- 喜剧担当之一：和莉娅互相吐槽，两个骚话王的巅峰对决

#### 弧光：从"逃避者"到"再战者"
- 前期：浑浑噩噩，混吃等死
- 中期：被莉娅感染，开始重新拿起武器
- 后期：重新找到了活着的意义——不是为了过去的遗憾，而是为了现在的伙伴
- 标志性台词："老子年轻的时候，可比你能折腾多了！"

### 4.3 神秘的"投影篡改者"·诺亚

#### 身份
- 神秘人物，性别不明（通常以少年形象出现）
- 自称"投影篡改者"
- 中期关键人物，连接"小世界"和"上层叙事"的桥梁

#### 功能
- 中期登场，告诉莉娅"世界的真相"——投影论四层（叙事＞宇宙＞世界＞小世界）
- 解释莉娅的穿越和誓约改签的本质——不是"规则漏洞"，而是"叙事层的干涉"
- 给莉娅提供升级到叙事层的方法
- 亦正亦邪——你永远不知道他站在哪边

#### 动机——他到底想干什么？
- 他是"上一个"穿越者
- 上一轮的"剧本"里，他是主角，但他失败了——世界被神灾毁灭
- 他用最后的力量"篡改了投影"，让世界重来一次
- 莉娅的穿越，其实是他"引"过来的
- 他的目的：让莉娅完成他没能完成的事——彻底打破"神灾循环"
- 但他的方法很极端——为了"最终的胜利"，可以牺牲一切
- 这也是他和莉娅的根本分歧：莉娅不愿意牺牲任何人

#### 与主线关系
- 中期登场：以"神秘人"的身份给莉娅提供线索，引导她发现世界的真相
- 中后期揭露身份：告诉莉娅一切真相，包括她自己也是"被安排"的
- 这成为莉娅人物弧光的重要转折点——从"剧本玩家"彻底觉醒为"命运创造者"
- 后期：成为亦敌亦友的存在——有时候帮莉娅，有时候给她制造麻烦
- 最终决战：和莉娅并肩作战，但用了"极端的方法"——牺牲自己来给莉娅争取机会
- 临终前笑着说："这一次……剧本终于不一样了。"

#### 弧光：从"操控者"到"相信者"
- 前期（幕后）：把莉娅当棋子，认为"只有按我的剧本走才能赢"
- 中期：发现莉娅一直在偏离他的"剧本"，而且偏离之后结果反而更好——开始动摇
- 后期：理解了"没有人有资格安排别人的命运"——选择相信莉娅，而不是相信自己的剧本
- 牺牲：用自己的方式"谢幕"——这一次，他不是主角，但他终于可以放心了

## 八、喜剧元素汇总（融入人设）

### 莉娅的骚操作合集
1. **抢誓约全靠骚**：每次改签誓约都不是靠"强抢"，而是靠各种奇葩操作——救猫、递水、接歌词、躲暗算、提前摆平违规……艾莉诺拉每次都晚来一步，气得跳脚
2. **艾莉诺拉追踪战**：艾莉诺拉天天堵莉娅，莉娅天天跑——跑着跑着就跑出了"圣约学院百米飞人"的传说
3. **剧本崩坏现场**：每次剧情偏离，莉娅的表情就像世界末日——结果每次都能靠骚操作圆回来（虽然越圆越偏）
4. **五倍的快乐，五倍的麻烦**：改签五条誓约线后，莉娅每天要应付五个性格迥异的女生——经常在不同的约会之间赶场，累并快乐着
5. **艾莉诺拉的怒火**：每次艾莉诺拉找到她，她的开场白都是"艾莉诺拉你听我解释！"——然后解释到一半就跑了

### 艾莉诺拉的逐渐迷惑
1. **第一阶段**："誓约小偷太嚣张了！"
2. **第二阶段**："她……为什么要帮她们？"
3. **第三阶段**："我为什么会在意她？"
4. **第四阶段**："不……不可能……"
5. **第五阶段**："……算了，认栽。"
