# 切片样本库

> 用户手动添加优秀网文片段。G2模仿学习门会从此目录加载切片作为写作参照。

## 目录结构

```
slices/
├── by_genre/                    # 按题材
│   ├── 古言宫斗/
│   ├── 都市职场/
│   ├── 玄幻修仙/
│   └── 悬疑推理/
├── by_technique/                # 按写作技巧
│   ├── 打脸场景/
│   ├── 情感爆发/
│   ├── 战斗场面/
│   └── 日常过渡/
├── by_scene/                    # 按场景类型
│   ├── 章首钩子/
│   ├── 章尾钩子/
│   ├── 对话驱动/
│   └── 内心独白/
└── by_author/                   # 按作者风格（可选）
```

## 如何添加切片

每个切片为一个 `.md` 文件，格式：

```markdown
---
source: 《书名》第N章
platform: 番茄/晋江/起点
author: 作者名
genre: 古言宫斗
technique: 打脸场景
metrics:
  sigma2: 17.2
  ttr: 0.55
  burst_cv: 0.53
  para_cv: 0.44
---

（粘贴200-800字的优秀片段正文）
```

## 添加建议

- 每个子目录放3-5个切片即可起步
- 切片需通过 `python tools/metrics.py 切片文件.md` 验证metrics达标
- 来源标注平台和作者，便于追溯
- 切片长度200-800字，聚焦一个技巧或场景
