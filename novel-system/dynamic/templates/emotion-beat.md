## 预警规则

- **连续同方向预警**：连续3章情感曲线方向相同（如连续3章上升或连续3章下降）→ ⚠️需在第4章设置情感转折
- **情感代偿缺失**：连续2章负面情绪未设置代偿 → ⚠️需在下一章提供情感释放
- **情感平淡**：连续3章情绪强度为"低" → ⚠️需提升情感张力

## 字段说明

| 字段 | 说明 |
|------|------|
| 主情绪 | 本章主导情绪（如：愤怒/期待/焦虑/感动/满足/恐惧） |
| 情绪强度 | 高/中/低 |
| 曲线方向 | ↑上升（情绪向好）/↓下降（情绪向坏）/→平稳（情绪持平） |
| 触发点 | 引发本章主情绪的剧情事件 |
| 情感代偿 | 本章提供的情感释放/补偿（如：打脸满足感/温暖互动/小确幸） |
| 连续同方向计数 | 当前连续同方向的章数，达到3触发预警 |
| 预警状态 | ✅正常 / ⚠️预警 / 🔴严重 |

## 情感弧线参考模式

> 以下为常用情感弧线模式，写作时可参考。

| 模式名称 | 走向 | 适用场景 |
|---------|------|---------|
| V字型 | ↓↓↑ | 先抑后扬，打脸爽文核心模式 |
| 波浪型 | ↑↓↑↓↑ | 持续拉扯，保持张力 |
| 阶梯上升型 | ↑→↑→↑ | 逐步积累，蓄力爆发 |
| 深V反弹型 | ↓↓↑↑↑ | 极度压抑后强烈释放 |
