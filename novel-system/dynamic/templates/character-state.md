## 字段说明

| 字段 | 说明 |
|------|------|
| 角色 | 角色姓名 |
| 当前位置 | 角色当前所处的物理位置/场景 |
| 当前情绪 | 角色当前的主要情绪状态（如：愤怒/期待/焦虑/平静） |
| 当前能力等级 | 角色当前的综合能力评级（如：S/A/B/C/D）或具体数值 |
| 当前关系 | 与主要角色的关系状态（如：与主角为敌对/同盟/暧昧） |
| 已知信息 | 角色已掌握的关键剧情信息（用简短列表记录） |
| 内心冲突等级 | 1-5级，1=无冲突，5=极度矛盾 |
| Soul Field压力点 | 角色的灵魂场域核心压力触发点（来自人物档案） |
| 最后更新章号 | 该角色状态最后更新的章节号 |
