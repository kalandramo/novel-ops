# 副线追踪表

> 追踪所有副线的出场频率和进度。G1加载时检查副线健康度，G6门禁执行副线检查。
> 每章写后更新：涉及副线的章节更新副线状态。

## 出场频率规则

- **最低频率**：每条活跃副线每8章至少出场1次
- **预警阈值**：副线超过6章未出场 → ⚠️预警，需在下2章内安排出场
- **严重预警**：副线超过10章未出场 → 🔴严重，必须在下1章强制安排
- **副线数量**：同时活跃的副线建议保持在2-4条，不宜过多分散注意力

## 副线阶段说明

| 阶段 | 说明 |
|------|------|
| 引入 | 副线首次出现，建立基础设定 |
| 发展 | 副线推进，线索逐步展开 |
| 活跃 | 副线高潮阶段，与主线交织 |
| 收束 | 副线即将收尾，回收线索 |
| 完成 | 副线已完结 |
| 暂停 | 副线暂时搁置（需标注原因和预计恢复时间） |

## 字段说明

| 字段 | 说明 |
|------|------|
| 副线名 | 副线名称/简称 |
| 出场章号 | 副线首次出场的章号 |
| 当前阶段 | 副线当前所处阶段（引入/发展/活跃/收束/完成/暂停） |
| 待回收线索 | 副线中尚未回收的关键线索列表 |
| 最后出场章号 | 副线最后一次出场的章号 |
| 距上次出场章数 | 当前章号 - 最后出场章号 |
| 预警状态 | ✅正常 / ⚠️预警 / 🔴严重 |
| 备注 | 补充说明 |

---

## 预警状态说明

| 状态 | 触发条件 | 处理方式 |
|------|---------|---------|
| ✅正常 | 距上次出场≤5章 | 无需处理 |
| ⚠️预警 | 距上次出场6-10章 | 下2章内安排出场 |
| 🔴严重 | 距上次出场>10章 | 下1章强制安排出场 |
