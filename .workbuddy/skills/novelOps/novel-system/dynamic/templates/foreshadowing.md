# 伏笔追踪表

> 记录所有伏笔的种植与回收状态。G1加载时检查超期伏笔，G3门禁执行风险预警。
> 每章写后更新：新种植伏笔登记入表，已回收伏笔更新状态和回收章号。

## 预警规则

* **黄色预警**：伏笔种植后超过20章未回收 → 标记为"⚠️超期"，需在下3章内回收或推进

* **红色预警**：伏笔种植后超过40章未回收 → 标记为"🔴严重超期"，必须在下1章内强制回收

* **回收完成**：伏笔回收后状态更新为"✅已回收"

## 伏笔类型

| 类型代码     | 类型名称 | 说明        | 示例         |
| -------- | ---- | --------- | ---------- |
| PROP     | 道具伏笔 | 某道具后续重要   | 神秘玉佩/旧信件   |
| INFO     | 信息伏笔 | 某信息后续关键   | 角色身世/世界秘密  |
| CHAR     | 角色伏笔 | 某角色后续重要   | 神秘路人/未登场角色 |
| PROPHECY | 预言伏笔 | 预言/梦境后续应验 | 预言某人命运     |
| MYSTERY  | 悬念伏笔 | 未解之谜      | 异常现象/神秘事件  |
| RELATION | 关系伏笔 | 角色间隐藏关系   | 两人实为兄妹     |

## 优先级

| 优先级 | 含义           | 回收要求         |
| --- | ------------ | ------------ |
| P0  | 核心伏笔（影响主线结局） | 必须回收，不得废弃    |
| P1  | 重要伏笔（影响重要情节） | 尽量回收，废弃需说明原因 |
| P2  | 次要伏笔（丰富细节）   | 可回收可废弃       |
