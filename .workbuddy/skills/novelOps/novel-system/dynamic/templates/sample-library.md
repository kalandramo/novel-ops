# 模仿样本库

> 存储用于语言风格模仿的样本数据。G4门禁执行AI味检测时参考样本库的统计指标。
> 步骤2.8（素材准备）阶段录入初始样本，每卷开始时刷新样本库。

## 使用规则

1. **每卷刷新**：每个新卷开始时，根据本卷的题材和风格需求更新样本库
2. **上限5个**：样本库同时保持不超过5个活跃样本，新增时淘汰最旧的
3. **指标参考**：样本的σ²/TTR/Pσ²/BurstCV/ParaCV/3gramUniq作为G5门禁AI味检测的目标区间参考
4. **适用匹配**：写作时根据章节类型（打脸/日常/情感/高潮）匹配最合适的样本

## 统计指标说明

| 指标 | 全称 | 含义 | 目标 |
|------|------|------|------|
| σ² | 句长方差 | 句子长度的变化程度，反映句式多样性 | 越高越好，说明句式变化丰富 |
| TTR | 词汇丰富度 | 不同词汇/总词汇的比率 | 越高越好，说明用词丰富 |
| Pσ² | 段落长度方差 | 段落长度的变化程度 | 越高越好，说明节奏变化丰富 |
| BurstCV | 句长变异系数 | 句长std/mean，GPTZero核心指标 | >0.50为佳 |
| ParaCV | 段长变异系数 | 段长std/mean | >0.40为佳 |
| 3gramUniq | 3-gram唯一率 | 不重复3-gram占比 | >0.90为佳 |

## 字段说明

| 字段 | 说明 |
|------|------|
| 样本ID | 样本唯一标识（如：SAMPLE-001） |
| 来源 | 样本来源（书名/作者/章节） |
| 题材 | 样本所属题材类型（如：都市/医美/系统/重生） |
| σ²参考 | 样本的句长方差值 |
| TTR参考 | 样本的词汇丰富度值 |
| Pσ²参考 | 样本的段落长度方差值 |
| BurstCV | 样本的句长变异系数 |
| ParaCV | 样本的段长变异系数 |
| 3gramUniq | 样本的3-gram唯一率 |
| 入场方式 | 样本的典型场景入场方式（如：对话入场/动作入场/环境描写入场） |
| 章末钩子类型 | 样本常用的章末钩子类型（C/D/R/E/T/P，见next-hook.md） |
| 适用章节 | 该样本最适合模仿的章节类型（如：打脸章/日常章/高潮章） |
| 状态 | 🟢活跃 / ⚪已归档 |
