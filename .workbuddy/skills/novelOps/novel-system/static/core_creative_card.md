## 一、世界/舞台：圣约大陆（小世界）

**设定**：
故事发生在"圣约大陆"——一个隶属于更大"世界"之下的**小世界**。这是一个勇者与神灾对抗的奇幻世界，拥有完整的"圣约誓约"魔法体系。大陆上有五大势力（教会/贵族/歌姬联盟/王室/学院），分别对应五位圣约女主的势力背景。

**对核心矛盾的不可替代性**：
1. 没有"圣约誓约"这套世界规则，"抢誓约改签"的核心爽点就不成立
2. 小世界的封闭性 = 主角前期的舞台边界，后期打破边界进入更上层世界/宇宙/叙事层，与升级路径深度绑定
3. 五大势力的空间分布 = 五条誓约线的地理动线，主角需要走遍大陆签下每一条誓约

**层级关系**：
```
叙事（最高·投影之源）＞宇宙＞世界＞小世界（圣约大陆）
```

## 二、行业：勇者圣约体系（奇幻冒险行业）

**设定**：
世界的核心"行业"是**勇者与神灾的对抗体系**。每隔一段时间会有"神灾"降临，只有被选中的"勇者"能通过与五位"圣约之人"立誓来获得神灾抗性和神威之力。勇者和圣约之人构成了世界的顶层战力阶层。

**权力结构**：
- 勇者：天选之人，世界的战力天花板
- 圣约之人（5位）：与勇者立誓后获得神威，各自代表一方势力
- 教会/王室/学院等机构：围绕勇者体系运转的世俗权力
- 普通冒险者/魔法师：底层战力阶层

**专业细节**：
- 誓约有严格的仪式和规则，不可随意签订或解除
- 断誓会导致勇者承压反升，但圣约之人失去神威
- 神灾有等级之分，对应不同级别的勇者需求
- "五圣约"机制：勇者与五位"圣约之人"各立一誓，誓约将勇者的神灾抗性分流给五人，五人相应获得神威反哺；一人断誓，勇者承压反升

**原游戏**：《闪耀吧！勇者的五圣约》——百合凤傲天游戏，主角前世玩过、知晓多世界线；"五圣约"＝勇者与五位关联女主的誓约路线（圣女/大小姐/歌姬/公主/学生会长）。

## 三、核心能力/金手指

### 金手指1：多世界线预知

**能力描述**：
主角出生即穿越（转生此世界长大），前世玩过《闪耀吧！勇者的五圣约》全路线，知道所有角色的背景、秘密、剧情走向和隐藏结局。

**代价/限制**：
1. **预知的是多世界线，不是既定事实**——穿越本身已造成偏离
2. **预知随剧情推进逐渐失效**——中后期"剧本全崩"
3. **只知道游戏里呈现过的内容**——游戏没写的（如投影论上层、神灾真相）一概不知
4. **预知信息可能是错的**——游戏里的"真相"可能是叙事层刻意编造的假象

### 金手指2：誓约改签（世界内真实规则的利用）

**能力描述**：
利用"五圣约"体系的规则漏洞——誓约不是绑定勇者本人，而是绑定"勇者的神灾抗性"。主角通过特殊方式将原本属于艾莉诺拉的誓约线改签到自己身上。每多一条誓约，获得一阶战力提升和对应女主的神威反哺。

**代价/限制**：
1. **改签一条誓约需要满足特定条件**（情感共鸣+仪式+时机），不是想签就签
2. **每改签一条，艾莉诺拉的神灾抗性就减弱一分，但承压反升**——她会变得更强也更危险
3. **五条全部改签后，会触发"五誓归一"的未知变化**（伏笔）
4. **誓约不是终身绑定**——如果女主主动解除，主角会失去对应的力量

## 四、核心矛盾：主角 vs 原勇者艾莉诺拉

**对手是谁**：
艾莉诺拉——原游戏的凤傲天主角，天选勇者，原本会收五位圣约女主建立后宫，最终拯救世界。本作被主角反收。

**为什么对抗**：
1. 主角穿越后发现自己是个"连立绘都没有的路人"，且按照原剧情会在某个事件中死去
2. 为了活下去，也为了改变那些她在意的角色的命运，主角决定"抢剧本"——把艾莉诺拉的誓约线一条一条改签到自己身上
3. 艾莉诺拉从"天选之子"的云端跌落，誓约一条条被抢走，她的骄傲、力量、身边的人都在失去
4. 两人从敌对→拉锯→动摇→最终走向"反收"的情感转变

**赌注**：
1. 主角的赌注：命（不改签誓约就会死）+ 在意的人的命运
2. 艾莉诺拉的赌注：勇者的身份、骄傲、以及她原本以为"属于自己"的一切
3. 世界的赌注：神灾正在逼近，如果勇者体系崩溃，谁来对抗神灾？
4. 更深层的赌注：投影论下，这个世界的"真实性"本身就是一个赌注

**认知设定补充**：
- 主角出生即穿越（转生此世界长大），穿越即偏离
- "预知"真实但有限（知道的是多世界线，不是既定事实），中后期"剧本全崩"

## 五、创意差异化

| 维度 | 现有爆款怎么做 | 我们怎么做不一样 |
|---|---|---|
| **核心梗** | 1v1攻略/拐走原女主 | **同时改签五条誓约线**，5倍爽点密度，每条线都是独立的打脸+情感+升级闭环 |
| **原女主定位** | 原女主是被攻略对象/反派炮灰 | **原女主反收**：艾莉诺拉是凤傲天，从"收后宫的人"变成"被收的人"，她本人就是最重要的情感线 |
| **世界观格局** | 止步于"游戏世界=真实世界" | **投影论四层宇宙观**：小世界→世界→宇宙→叙事层，从"抢誓约"一路升级到"对抗叙事意志"，格局天花板极高 |
| **多女主关系** | 后宫争宠/雌竞 | **去雌竞化女性群像**：五位女主各有独立人格和成长线，从"潜在情敌"变成"并肩作战的伙伴" |
| **喜剧元素** | 身份错位小打小闹 | **抢誓约喜剧引擎**：每改签一条誓约都有误会、身份错位、艾莉诺拉逐渐迷惑的喜剧效果，喜剧和战力升级双线驱动 |
| **预知设定** | 预知=金手指=全知全能 | **多世界线预知=有限且会失效**：穿越即偏离，剧本全崩，预知从"答案"变成"陷阱"，制造中后期反转 |

**投影论关键补充**：
- 游戏/文艺作品/梦境，可能是另一个世界的真实投影
- 不同世界互为投影
- 无数宇宙本身也互为投影，其源头＝最初的神兽（＝第一叙述意志，站在故事之外）
- 这解释主角"预知"的来源，也是从"宇宙级"一路升到"叙事层/上层叙述级"的入口
- **不加彩蛋**：游戏里不残留"最初神兽"痕迹
